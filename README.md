# Monchosos Gestor (Flutter)

Versión en Flutter de [Gestor_Hamburgueseria](https://github.com/CiscoPaquitoTracer/Gestor_Hamburgueseria), la app para llevar el día a día de **Monchosos**: pedidos, cobros, inventario y resumen de ventas.

Se reescribe en Flutter para tener una sola base de código para **Android** e **iOS** (la plataforma web se genera, pero no se usa).

## Cómo correrlo

```bash
flutter pub get
flutter run
```

## Estado

Proyecto recién creado. La migración desde la app Kotlin/Compose está en curso.
